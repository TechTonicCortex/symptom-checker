# SymptomSense — Symptom Checker

**Click where it hurts and learn about common causes. Educational only.**
Open `index.html` in a browser.

## ⚠️ This is not medical advice
It cannot diagnose anything. If someone is seriously unwell, call a doctor, a nurse line, or 911.

## What it does
- Click a body region to see common symptoms, then add them to the symptom box
- Look things up by age group and how long the symptoms have lasted
- Keeps a history in your browser. **Clear all history** deletes it.

## How it works
It's a **built-in lookup of information**, not live AI, despite the "AI" in the title. All data is stored in the file and history is saved in your browser's `localStorage`. Nothing is sent anywhere.

## Limits (honest)
- Information is general and needs a check against trusted sources like Health Canada before sharing widely.
- Symptoms overlap a lot between conditions, so only a clinician can sort them out.
- **Rename it if the "AI" label isn't accurate.**
